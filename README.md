# Student Management System

## About the Project
This is a console-based Student Management System
developed using Java, JDBC, and MySQL.

## Features
- Add Student
- View Students
- Update Student Details
- Delete Student

## Technologies Used
- Java
- JDBC
- MySQL
- MySQL Connector/J
- VS Code

## Database
Database Name: studentdb
Table Name: students

## How to Run
1. Install Java JDK.
2. Install MySQL and create the database.
3. Add MySQL Connector/J to the project.
4. Update the database credentials in the Java code.
5. Compile and run the program.

## Concepts Used
- CRUD Operations
- PreparedStatement
- Exception Handling
- JDBC Database Connectivity
- Try-with-resources
